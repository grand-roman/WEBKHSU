# Темы для 3 практической

Основы и контейнеризация:
1. Flask и Docker: контейнеризация легковесных приложений.
2. Аутентификация и авторизация в Flask (Flask-Login, JWT).
3. Миграции в Flask: Alembic и Flask-Migrate.
4. Асинхронный Flask: asyncio и Quart (Flask 2.0+).
API и REST:
5. RESTful API с Flask-RESTful и Flask-RESTX.
6. Оптимизация производительности Flask-приложений.
7. Тестирование в Flask: pytest, unittest, coverage.
8. Flask + SQLAlchemy: работа с базами данных.
Продвинутые возможности:
9. Загрузка файлов и работа с медиа в Flask.
10. Интеграция Flask с React/Vue.js (SPA архитектура).
11. Сигналы в Flask: blinker и обработка событий.
12. Кэширование в Flask: Flask-Caching, Redis.
Фоновые задачи и реал-тайм:
13. Flask + Celery: фоновые задачи и очереди.
14. Безопасность Flask: CSRF, rate limiting, OWASP.
15. Flask Admin: кастомный административный интерфейс.
16. Flask и PostgreSQL/MySQL: продвинутые запросы.
Деплой и DevOps:
17. Деплой Flask: Gunicorn + Nginx + Docker.
18. Flask-SocketIO: WebSocket и реал-тайм.
19. Локализация Flask-приложений (Flask-Babel).
20. GraphQL API с Flask: Graphene-Flask.
21. Мониторинг Flask: Sentry, Prometheus + Grafana.
22. Flask Blueprints: модульная архитектура больших приложений.
